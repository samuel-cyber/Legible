## What this says about the scope

Channel B needs the construct to be expressible as (symbol, context) tokens: bases, sub/superscripts, fractions (a horizontal rule with glyphs above and below) and accents. Summations, integrals, radicals and partial derivatives reduce to exactly those, so they verify. Binomial coefficients (two rows with no bar) and floor/ceiling brackets reduce to constructs the vocabulary has no token for, so they fail closed. Because Channel A is an independent reading, a wrong glyph reading, a wrong transcription, or a construct either channel cannot represent all end in the same place: **withheld, never published**.
